2024년 가을학기 디자인적사고 프로젝트

3명이 조를 이룸. 본인은 flask를 이용한 서버 및 api 부분 담당함.
전체 프로젝트는 본인 깃허브 프로필의 organization의 cg를 참고하세요.

mysql과 heidisql을 사용해서 상품 정보와 이미지 경로를 테이블 형태로 저장.
flask서버는 클라이언트로부터 상품 id를 받아서 그에 맞는 json으로 보내준다.

기능은 세가지이다.
/upload는 클라이언트로부터 이미지 파일을 post받는다. 그리고 인공지능 모듈을 돌려서
나온 상품의 ID를 클라이언트에게 전송한다. 클라이언트는 Id를 받아서 상품 정보를 요청한다.
모듈은 이 리포지토리에 담겨 있지 않다. CG organization을 참고하세요.

/ID=n (int)는 n이라는 ID를 가지고 있는 상품정보를 리턴한다.
상품 이름, 상품 가격, 행사정보를 json형태로 리턴한다.

/history=n (int)와 history_image=n (int)는 mysql 테이블 중에서 history 테이블의
데이터를 전송한다. history 테이블은 유저가 전송한 이미지 파일이 모듈에서 통과되면
이미지 파일의 경로와 모듈에서 나온 Id의 상품정보를 저장한다.
history ID는 autoincrement이고 내림차순으로 정렬되어 있다.
유저가 n=1을 입력해서 히스토리 정보를 요청하면 최신순으로 1번째 데이터를 리턴한다.
